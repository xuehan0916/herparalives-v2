# 开发预览说明（2026-10-21）

需求来源：[HerParaLives 产品方案（10/14 版）](https://my.feishu.cn/docx/C3zpdm2LxoYcAGxuM2TcbjrLnpb)，读取 revision 222，包含 10/20 反馈。原文快照保存在项目上层 docs，未提交到代码仓库。

## 当前可体验

故事馆首页、卡牌翻面、处境卡、一屏一场景、字号调整、五章十五次选择、即时反馈、早期选择的后果回响、章末五维示意及回望、章末碎片、结局、选择记录、本地保存与读取。

林遥故事为 AI 辅助原创虚构开发样篇，尚未内容审校，不属于正式策展内容。样篇用来验证流程，其分支和回望仍需进一步制作；不能作为正式的十五分钟内容验收。首页不沿用旧项目五条故事。

## 开发规则

- 五维先按 10/20 反馈采用安稳、自由、成就、关系、自我，描述角色处境，不给用户评分。
- 每条五章，每章三次选择；每章一枚碎片，取多数维度，三种不同时取最后一次。
- 五种各一枚兑换一次个人体验，每四条故事保底；沿用仓库已有纯逻辑，但当前界面不发放正式权益。
- Coach 不与碎片绑定。当前章末为预制回望，尚未实现逐路线精确的个性回望。
- 真实账号、服务端存档、权益兑换、分享奖励、AI 脱敏和生成、角色确认、结局五维趋势线尚待开发。未接入个人功能前不收集现实困惑。
- 本地记录只保存在当前浏览器，可通过图鉴读取；浏览器清理会丢失。

## 运行

Node 22 或以上。`npm ci`，然后 `npm run dev -- --hostname 127.0.0.1`，打开 http://127.0.0.1:3000 。也保留 pnpm 工作区和锁文件；两种安装方式均需遵守 package.json / pnpm-workspace.yaml 的依赖覆盖。

检查：`npm run lint`、`npm test`、`npm run build`。新增测试覆盖完整十五次选择、五枚章末奖励和后果引用的有效性。

原仓库下载于上层 reference-original，仅作读取参考。当前仓库 origin 仅指向 y1234567x-source/herparalives-v2，不连接旧站点部署。
