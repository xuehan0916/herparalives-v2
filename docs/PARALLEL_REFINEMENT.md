# 回到第一版，仅减轻鬼魅感 · 2026-11-04

用户明确更偏爱第一版旋涡和平行人生的游戏氛围，以及原来的抽卡故事馆。本轮以 ca3d96a 的开屏、卡牌布局和配色为基础恢复，不继续沿用纪实海报、人物名人堂或上下分区方案。

## 小幅调整

- 保留原始女性群像旋涡背景，适度提亮并减弱雾化压暗。关闭底图呼吸缩放。
- 加入七条纵深弧形平行轨迹，让空间线路承担主要动势。
- 动态人物从 28 个减少到 12 个，保持直立，取消歪斜旋转与绕圈。速度减慢，缩小近景尺寸，为中央标题保留空间。
- 人物绘制透明度固定为 0.92，取消反复透明叠影。减少背景纹理与人形层叠，避免原版的漂浮幽灵感。
- 暂停、减少动态效果、隐藏页面暂停、画布分辨率上限和清理逻辑沿用原实现。

## 故事馆

恢复分类卡组、拱形牌面、翻牌、抽卡提示、被抽中卡牌置顶与体验按钮。继续保留分类简介、搜索、来源筛选和可跳过的登录提示。

故事角色仍应按故事单独建立。没有 `card.portrait` 时显示独立的窗与版画概念牌面，并标注「角色待建立 · 封面示意」，不借用首页女性。现有开发样篇不当作正式故事，也不新增虚构目录条目。

本轮没有生成或编辑位图，继续使用第一版 `public/images/lives-vortex.png`、`public/images/women-silhouettes.png`。过去的多轮素材与样式保留作记录，layout 不再加载这些后续探索样式。
